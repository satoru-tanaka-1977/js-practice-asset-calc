# js-practice-asset-calc

JavaScriptの学習の一環としてコツコツ作成している、複利計算による資産シミュレーションアプリです。

## 概要
毎月の積立額、年利、積立期間を入力することで、複利の効果によって資産がどのように増えていくかを計算・可視化するためのツールです。

## 学習のポイント・こだわり
- **1日1行からの丁寧な積み上げ**: コードの意味や英単語の構造を一つひとつ理解しながら、手打ちで実装を進めています。
- **論理構造の意識**: プログラムを「入力（Input）」「計算（Processing）」「出力（Output）」のブロックに整理し、基礎からしっかりと組み立てています。
